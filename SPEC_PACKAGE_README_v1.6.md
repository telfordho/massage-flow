# Massage Flow — Specification Package v1.6

This package preserves the complete v1.5 base specification as `Massage_Flow_Spec_Package_v1.5.zip` and adds `SPEC_ADDENDUM_v1.6.md`.

Read the v1.5 documents first, then apply the v1.6 addendum. The addendum introduces the local AsyncStorage continuity layer, completed-session history, subjective feedback persistence, UUID v4 session identifiers, and the preview-gated repeat-flow entry point. It does not replace the existing wellness boundary, deterministic program rules, or controlled preview-edit limits.

The runnable code baseline for this specification package is `Massage_Flow_Prototype_Source_v1.1.zip`.
